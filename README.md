# VIGNAN SMART ACCESS

A presentation-ready student project prototype for Vignan's Foundation for Science, Technology & Research (Deemed to be University), Vadlamudi.

## Run
Open `index.html` in Chrome/Edge/Firefox. No server or hardware is required.

## Included
- Dashboard
- Campus Map
- Gate Access + six-agent verification pipeline
- Visitor Management + simulated QR pass
- AI Agents
- Access Logs + filters + CSV export
- IoT Devices + simulated device events
- Alerts + resolution workflow
- Run Demo
- Future RFID RC522 -> ESP32 -> Wi-Fi -> Backend/Firebase -> AI Risk Engine -> Dashboard -> Gate Controller architecture

## Important
All data and IoT/AI activity are simulated prototype data. No real Vignan University security system or hardware is connected.
